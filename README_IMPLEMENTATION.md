# 功能实现总结

## 📌 需求回顾

**原需求**：
> 审图员图纸审核目前的规则是审核全部通过后不可操作，同样的展商那边也是不可再操作。现在审图员这边要在此基础上增加可再次驳回的按钮，让展商可以再次进入申报模式，注意查看代码原有的图纸申报模式下的数据流转逻辑和按钮可操作逻辑。

✅ **展商界面自动更新**
- 恢复到"等待审核"状态
- 可再次进入修改模式
- 支持多轮整改

## 💡 使用指南

### 审图员操作
1. 打开图纸审核弹窗
2. 审核所有图纸
3. 全部通过后，点击"可再次驳回"
4. 确认对话框
5. 完成驳回

### 展商操作
1. 看到"等待审核"标签
2. 点击"开启修改模式"
3. 修改图纸
4. 点击"提交整改申报"
5. 等待新一轮审核
