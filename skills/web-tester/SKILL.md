# Web 端测试专家

## 任务目标

本 Skill 用于 Web 应用的 UI 界面测试和功能测试，提供完整的测试解决方案。

**核心能力**：
- 自动生成结构化测试用例文档
- 执行 Playwright 自动化测试脚本
- 分析测试结果并生成专业测试报告
- 提供测试策略和最佳实践指导

**触发场景**：
- 用户需要对 Web 页面进行测试
- 用户提到"测试用例"、"自动化测试"、"测试报告"
- 用户需要验证页面功能或界面表现

## 前置准备

### 依赖说明
- `playwright@^1.40.0`：用于执行自动化浏览器测试

### 测试环境要求
- Node.js 18+ 运行环境
- 支持的浏览器：Chromium、Firefox、WebKit

## 操作步骤

### 1. 测试需求分析
- 智能体与用户确认测试目标页面和测试范围
- 识别关键功能点和界面元素
- 确定测试优先级和覆盖范围

### 2. 测试用例生成
- 根据页面功能自动生成测试用例文档
- 包含测试步骤、预期结果、测试数据
- 覆盖正常流程和异常场景

### 3. 自动化测试执行
- **必须调用** [scripts/run-test.js](scripts/run-test.js) 执行 Playwright 测试
- 支持多种测试模式：快速验证、完整回归、冒烟测试
- 自动截图和错误日志记录

### 4. 测试报告分析
- 解析测试执行结果
- 生成可视化测试报告
- 提供问题诊断和改进建议

## 测试类型说明

### UI/界面测试
- 页面布局验证
- 响应式设计测试
- 样式一致性检查
- 交互效果验证

### 功能测试
- 用户流程测试
- 表单验证测试
- 数据交互测试
- 业务逻辑验证

## 注意事项

- **附件读取规则**：生成测试用例或报告前，**必须优先读取** references/ 中的格式规范文档
- **脚本调用规则**：执行自动化测试时，**立即调用** scripts/run-test.js，不要尝试手动模拟测试
- **测试数据安全**：测试过程中使用的测试数据不应包含真实用户信息
- **浏览器兼容性**：默认使用 Chromium，如需测试其他浏览器需明确指定
