# Word 文档智能分段工具使用说明

## 功能介绍

这个工具可以读取 Word 文档（.docx 格式），并按照指定字数智能分段，保持语义连贯。

## 核心特性

1. **智能分段** - 每段约 500 字，在语义边界处切分（段落、句号、逗号等）
2. **重叠处理** - 相邻段落有 50 字重叠，确保上下文连贯
3. **避免短段** - 自动合并过短的末尾段落（小于 150 字会合并到前一段）
4. **多种输出** - 控制台打印 + JSON 文件保存

## 安装依赖

```bash
npm install mammoth
```

## 使用方法

### 方法 1：基础版（仅控制台输出）

```bash
node scripts/split-docx.js
```

### 方法 2：增强版（控制台 + JSON 文件）

```bash
node scripts/split-docx-enhanced.js
```

## 核心算法说明

### 1. 语义分隔符优先级

```javascript
const separators = [
  '\n\n',      // 段落分隔（最高优先级）
  '\n',        // 换行
  '。',        // 句号
  '！',        // 感叹号
  '？',        // 问号
  '；',        // 分号
  '，',        // 逗号
  ' ',         // 空格（最低优先级）
];
```

### 2. 分段逻辑

1. 从起始位置开始，计算目标结束位置（起始 + 500 字）
2. 在结束位置向后搜索 100 字范围内的语义分隔符
3. 找到分隔符后，在该位置切分
4. 下一段起始位置 = 当前结束位置 - 50 字（重叠）
5. 如果剩余文本少于 650 字（500 + 150），直接合并到当前段

### 3. 重叠示例

```
段落 1: [0 -------- 500] (500 字)
段落 2:         [450 -------- 950] (500 字，与段落 1 重叠 50 字)
段落 3:                  [900 -------- 1400] (500 字，与段落 2 重叠 50 字)
```

## 自定义参数

如果需要修改分段参数，编辑脚本中的 `smartSplit` 函数调用：


## 常见问题

### Q: 为什么有些段落不是正好 500 字？

A: 为了保持语义连贯，脚本会在语义边界处切分（如句号、段落分隔符），所以实际长度会在 450-550 字之间波动。

### Q: 重叠的 50 字有什么用？

A: 重叠可以确保上下文连贯，特别是在使用 AI 处理时，可以避免因切分导致的语义断裂。

### Q: 如何处理其他格式的文档？

A: 目前只支持 .docx 格式。如果是 .doc 格式，请先用 Word 另存为 .docx。

### Q: 可以批量处理多个文档吗？

A: 可以修改脚本，使用 `fs.readdirSync` 遍历目录中的所有 .docx 文件。
