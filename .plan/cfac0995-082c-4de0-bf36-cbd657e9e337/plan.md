# 缴费通知单功能实现计划

## 任务概述
在审图员账号的"申报情况"板块中，增加"生成缴费通知单"功能，支持在线填写和下载PDF。

## 需求分析

### 1. 基础功能
- 在操作栏增加"生成缴费通知单"按钮
- 点击后弹出表单弹窗，可填写/修改通知单内容
- 支持下载PDF文件

### 2. 表单类型
**普通展位（高度<4.5m）**：
- 生成"展会服务缴费通知单"（参考图一样式）

**超高展位（高度≥4.5m）**：
- 生成两个表单：
  - "展会服务缴费通知单"（样式同图一）
  - "超高审图缴费通知单"（参考图二样式）
- 各自有独立的下载PDF按钮

### 3. 表单字段

**展会服务缴费通知单**：
- 基本信息：展览名称、展馆、展位、展商名称、审图编号
- 费用明细表格：序号、项目、数量、单位、单价、押金、金额、备注
- 汇总：小计、总计
- 注意事项
- 收款信息：收款户名、银行账号、开户银行、联行号、银行代码
- 咨询联系方式

**超高审图缴费通知单**：
- 收件信息：收件单位、收件人、电话、E-mail、展位号
- 发件信息：审图服务商、发件人、电话、E-mail、日期
- 费用说明：根据贵公司的报图，审图费用如下
- 费用表格（自动生成）
- 注意事项（4条）
- 公司信息：公司名称、公司地址、电话、开户银行、银行账户

## 技术实现方案

### 1. 前端修改
**文件**：`src/components/ApplicationOverview.tsx`

修改内容：
1. 在操作栏增加"生成缴费通知单"按钮
2. 添加状态管理：
   - `showPaymentNoticeModal` - 控制展会服务缴费通知单弹窗
   - `showHeightNoticeModal` - 控制超高审图缴费通知单弹窗
   - `paymentNoticeData` - 展会服务通知单表单数据
   - `heightNoticeData` - 超高审图通知单表单数据
3. 实现表单弹窗组件：
   - 可编辑的表单字段
   - 费用明细自动计算
   - 下载PDF按钮
4. PDF生成：使用浏览器端PDF生成库（如html2pdf.js或jsPDF）

### 2. PDF生成方案
使用 `html2pdf.js` 库：
- 将表单内容渲染为HTML
- 使用html2pdf转换为PDF下载
- 支持中文显示

### 3. 依赖安装
```json
{
  "dependencies": {
    "html2pdf.js": "^0.10.1"
  }
}
```

## 实施步骤

3. 实现展会服务缴费通知单弹窗和表单
4. 实现超高审图缴费通知单弹窗和表单
